        Como editar

        • Clique num elemento para escolher. Arraste para mover.
        • Puxe um canto para mudar o tamanho. Para um tamanho exato, digite a porcentagem em Tamanho e aperte Enter.
        • Clique duas vezes num texto para escrever nele no palco. Enter quebra a linha. Ctrl+Enter ou um clique fora aplica, e Esc desiste.
        • Para mexer em vários juntos, segure Shift e clique em cada um. O botão Escolher vários faz o mesmo.
        • Você também pode arrastar um retângulo em volta dos elementos. Comece o arraste num espaço livre do palco.
        • Para encostar na margem ou centralizar, use os botões de Alinhar.
        • Para alinhar as linhas de um texto à esquerda, ao centro ou à direita, use os três botões depois de Quebrar linha. A linha mais longa fica no lugar.
        • Pelo teclado, as setas movem, + e - mudam o tamanho, F2 abre o texto escolhido e Delete apaga.
        • Ctrl+Z ou Desfazer volta a última edição. Esc tira a escolha.
        • Você edita este arquivo. Os outros arquivos da família seguem o layout dele.
